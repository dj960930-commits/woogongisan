  4. 암호화 저장하고 메리츠 연결을 누릅니다.

키·계좌 기록은 기기에 암호화 저장합니다. 메리츠 공식 서버에 직접 인증하며 GitHub로 전송하지 않습니다. PC 서버·Tiingo·Firebase 없이 계좌를 조회할 수 있습니다. 이 연결 기능은 주문을 보내지 않습니다.

계좌 조회와 모델 결과

메리츠 계좌는 직접 조회합니다. 모델 결과는 Yahoo Finance·Bitstamp의 완료 종가로 자동 계산합니다. 앱의 ‘오늘 → 최신 결과 확인’을 누르면 최신 완료 거래일의 목표·그래프를 받아옵니다. 메리츠 계좌 연결과 모델 시세 조회는 별개이며 추가 키는 필요하지 않습니다. 개인 계좌 순투입금·전체 입출금 분류·개인 계좌와 TQQQ의 비교는 별도 미완료입니다. 장 마감 알림은 기기 자체 알림을 사용합니다.

총자산은 메리츠가 제공한 평가액입니다. 보유 종목 평가수익률은 실현손익·배당을 포함한 계좌 누적수익률과 다릅니다. 기기 절전·통신·API 권한에 따라 조회가 지연될 수 있습니다. 실제 휴대폰 계좌 대조가 필요합니다.

장 마감 확인·휴장일 안내

2.0는 미국장 마감 5분 뒤 휴대폰 확인을 시작합니다. 서머타임·조기 폐장을 반영하고, 휴장일에도 같은 시간대에 최신 결과를 안내합니다. 설정 → 장 마감·휴장일 알림 → 알람 및 리마인더 허용하기를 눌러 정확한 확인 시간을 허용해 주세요. ‘알림 테스트’로 알림 권한도 확인하세요.

이 시간은 결과 확정 보장이 아닌 확인 시작 시간입니다. 서버가 아직 계산 중이면 대기를 표시합니다. 서버 계산·통신·기기 절전으로 결과 알림이 지연될 수 있습니다. 서버 결과를 기다릴 때 재시도하며 조회 캐시를 갱신합니다. Firebase 서버 푸시는 아직 미연결입니다. 실제 기기 수신 검증은 업데이트 후 필요합니다.
